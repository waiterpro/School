ШКІЛЬНИЙ РОЗКЛАД — без Google Apps Script

ВИМОГИ: Python 3.10+; інтернет; таблиця Google має дозволяти завантаження XLSX у режимі перегляду.

WINDOWS:
1. Встановити Python з https://www.python.org/downloads/ (під час установки увімкнути Add Python to PATH).
2. Розпакувати всі файли архіву.
3. Запустити start_windows.bat.
4. У браузері відкрити http://localhost:8000.

СЕРВЕР / ХОСТИНГ:
- pip install -r requirements.txt
- python app.py
- Виставити змінну PORT, якщо хостинг вимагає інший порт.
- Для постійної роботи потрібен сервер/хостинг, який запускає Python (не просто статична HTML-сторінка).

Робота: сервер завантажує XLSX з адреси Google Sheets /export?format=xlsx, зчитує ВСІ поточні merged ranges через openpyxl і повертає розклад браузеру. Кеш 60 хвилин; кнопку «Оновити» можна натиснути для перевірки без очікування. Якщо Google недоступний, показується явно позначений старий приклад sample.xlsx. Його не можна вважати актуальним розкладом.

УВАГА: якщо власник обмежив експорт/завантаження або вимагається вхід, автоматичне оновлення не буде працювати. У такому випадку потрібен дозвіл на завантаження або авторизований доступ на сервері. Власник таблиці нічого не повинен змінювати за умови доступного експорту.
